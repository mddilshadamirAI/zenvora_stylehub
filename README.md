# Zenvora Stores — Frontend Website

Official website and digital brand identity for **Zenvora Stores**, owned and operated by **Tabish Raja**. 

Active marketplaces: **Amazon, Flipkart, and Meesho**.
Main product verticals: Earrings, Jhumkhas, Suits, and Fashion Jewellery.

## Architecture & Design
- **Built with:** Semantic HTML5 and pure CSS3 (utilizing CSS Custom Properties / Variables for easy skinning).
- **Design Theme:** Luxury Minimalist / Modern Indian E-commerce (Deep Charcoal `#1A1A1A`, Ivory/Neutral Beige `#F9F8F6`, and Subtle Gold `#C5A059`).
- **Responsive System:** Fluid CSS Grid and Media Queries for seamless responsiveness across Desktop, Laptop, Tablet, and Mobile devices.

## Future Expansion Readiness
The codebase is structured with clear, repeating semantic patterns designed for seamless transition into dynamic environments:
1. **Product Management:** Product cards utilize consistent classes (`product-card`, `product-img-wrapper`, `product-title`, `product-price-row`) that can easily be mapped to a JSON database or Node.js/PHP backend.
2. **Dynamic Scripting:** Cart, wishlist, and search buttons are laid out in the header and product views, ready for event listeners and state management via JavaScript.
3. **Marketplace Integration:** Placeholder URLs (`#amazon-link`, `#flipkart-link`, `#meesho-link`) are in place across product cards and dedicated sections for direct ASIN/product link replacement.
